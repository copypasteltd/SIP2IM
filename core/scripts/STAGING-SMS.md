# Local staging SMS harness

**The operator must independently verify that the Core behind the configured port is isolated staging, including database, workers, integrations and connected devices.** Literal loopback and opt-in are not proof: a local proxy or forwarded port can reach production, and other devices can be connected. Never run against production or with real devices connected. In particular 12345 is only a fake peer in this harness; it can be a real short code outside an isolated setup.

Use only a dedicated staging administrator token and a fresh staging binding code supplied externally. Set CORE_STAGING_OPT_IN=yes, CORE_STAGING_ORIGIN to a literal http://127.0.0.1:PORT or http://[::1]:PORT, CORE_STAGING_ADMIN_TOKEN and CORE_STAGING_BINDING_CODE in the process environment by a secure mechanism. From core run node scripts/staging-sms.mjs. Do not put secrets in arguments, logs, history or source; clear them afterwards. This script starts no service. Do not run it in ordinary tests.

A uniquely named synthetic device is bound, an unpaused heartbeat and authoritative ready synthetic SIM snapshot are sent, and the correlated snapshot ACK and authenticated device/SIM listing checked. The one SMS POST targets that SIM and fake peer 12345. The harness buffers WebSocket frames before awaiting the HTTP reply, checks command identity and contents against the created task, acknowledges it, verifies accepted via the authenticated idempotency read, then sends a fake sent result and checks its ACK and persisted sent state. No device, cellular network, SMS or call is exercised. This only demonstrates simulated server-side flow. Redirects are refused; response/error data and credentials are not printed, though server logs are outside the harness's control.

Writes and socket sends are never implicitly retried. A lost response can mean a bind, POST, ACK, result or revocation occurred despite failure: inspect staging manually before any retry. Finally the socket is closed and the known synthetic device soft-revoked once; authenticated GET verifies 404. A failed or interrupted bind may leave an unknown device, and soft revocation leaves records, SMS task and idempotency state in staging. Cleanup failure is reported. The heartbeat has no independent wire ACK; the list validates its observed state.
