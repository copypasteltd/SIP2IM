# 10 决策与风险登记

> 版本 1.2 · 2026-11-20

## 1. 架构决策（ADR）

| 编号 | 决策 | 状态 |
|---|---|---|
| ADR-001 | 不使用 SIP，自定义协议 | 已决定 |
| ADR-002 | 项目 MIT；独立实现，不复用 GPL 代码 | 已决定 |
| ADR-003 | 业务 APK + Shizuku，免 Root | 已决定，待 G0 |
| ADR-004 | ~~SQLite~~ | **已废止**，由 ADR-010 取代 |
| ADR-005 | 浏览器音频用 WebSocket PCM + AudioWorklet，不用 WebRTC | 已决定 |
| ADR-006 | 平台适配器为独立进程，Unix socket 通信 | 已决定 |
| ADR-007 | Admin API 用 Bearer 令牌，不用 Cookie | 已决定 |
| ADR-008 | 媒体内部 PCM16 单声道 20 ms；手机 16 kHz、平台 48 kHz | 已决定 |
| ADR-009 | 每个平台通道每次 1 通；两通道可各 1 通 | 已决定 |
| ADR-010 | PostgreSQL 14，新建独立集群 voip（端口 47432），复用已有 PG 14 与 postgres 系统用户，不碰现有集群 | 已决定 |
| ADR-011 | 单 APK，minSdk 19，按 L1–L5 能力分级（见 03） | 已决定 |
| ADR-012 | 修订：QQ 与 Telegram 通道可同时存在，各 1 个配对用户；短信与提醒发两边；语音来电只转给设置中的来电平台；新配对替换该平台旧配对；无路由页 | 已决定（第三轮修订） |
| ADR-013 | 修订：回铃优先透传运营商早期媒体；检测不到时循环播放“接通中”提示语音；不生成其他任何音 | 已决定（第三轮修订），待 G0 |
| ADR-014 | 服务全部 root 运行，不新增系统用户 | 已决定 |
| ADR-015 | 服务端兼容 Node 20/22，使用服务器现有 Node 20.20.2 | 已决定 |
| ADR-016 | QQ 优先，两平台同步；QQ 失败按 Q-A→Q-B→Q-C 换方案继续 | 已决定 |
| ADR-017 | 三种语言：zh-CN、zh-HK、en | 已决定 |
| ADR-018 | 核心服务端口 47860 | 已决定 |
| ADR-019 | 网关手机充电线接服务器 USB 口，服务器 adb 自动启动 Shizuku | 已决定 |
| ADR-020 | 短信转发两边；配对用户可用消息命令发短信（P1） | 已决定 |
| ADR-021 | 本机安装 JDK 17 / Android SDK / Gradle 于 VOIP/.toolchain（不入库），本机构建；发布签名存本机密码库 | 已决定 |
| ADR-022 | 仓库根目录即 VOIP/，docs 随代码入库开源，对外发布名 voip-gateway | 已决定 |
| ADR-023 | 短信速率只在 core 限制；设备端不限速 | 已决定 |
| ADR-024 | 非配对用户发送 8 位数字视为配对码；已配对用户需“绑定”前缀才视为配对码，纯 8 位数字按 +852 号码处理 | 已决定 |

## 2. 风险登记

| 编号 | 风险 | 可能性 | 影响 | 应对 |
|---|---|---|---|---|
| RISK-01 | Z20（Android 9/10）无 Android 13 上行注入接口，旧式路由可能失败 | **高** | 极高 | G0 先测上行；失败时由用户决定换机或收缩范围 |
| RISK-02 | 系统更新使隐藏接口失效 | 中 | 高 | 关闭网关手机自动更新；每次通话前探测 |
| RISK-03 | Telegram 通话库不稳定或许可证不兼容 | 中 | 高 | 独立进程；T-B 备选 |
| RISK-04 | QQ 在 x86_64 + MIT 下难以实现 | 高 | 高 | 三条备选路线 |
| RISK-05 | 桥接账号被封 | 中 | 高 | 专用账号；告警；来电平台被封即转接中断（不自动切换） |
| RISK-06 | 配对码泄漏 + 无次数限制 → 盗打 | 低 | 高 | 用户已接受；短时效、单次、错误锁定、可解除 |
| RISK-07 | 磁盘空间不足 | 高 | 中 | 用户已接受（C-09） |
| RISK-08 | 无备份导致数据丢失 | 低 | 高 | 用户已接受 |
| RISK-09 | 关闭 CORS 被跨站调用 | 低 | 中 | Bearer 令牌 |
| RISK-10 | Z20 重启后 Shizuku 需 ADB 启动 | 中 | 中 | 充电线接服务器自动启动（ADR-019）；需服务器 USB 口与线长满足摆放 |
| RISK-11 | 先拨后回拨，被叫先接产生话费 | 中 | 低 | 用户已接受 |
| RISK-12 | 来电平台正在通话时，其他来电全部不应答 | 高 | 中 | 提醒两个配对用户 |
| RISK-13 | 运营商回铃由手机本地生成时无法透传 | 中 | 低 | 循环“接通中”兜底（用户同意） |
| RISK-14 | Node 20 已过官方维护期 | 中 | 低 | 代码兼容 22，日后可升级 |
| RISK-15 | 全部 root 运行，任何漏洞即获最高权限 | 中 | 高 | 用户已接受（C-06）；最小暴露端口 |
| RISK-16 | Android 4.4–5.0 设备只能做短信 | 确定 | 低 | 能力分级如实展示 |
| RISK-17 | 配对用户未加好友或 Telegram 隐私设置拒绝来电，导致回拨/转接失败 | 中 | 中 | 配对说明与成功回复中提示；失败原因回传 |
| RISK-18 | Android 4.4–5.x 无法实机验证 | 确定 | 中 | 编译检查；有旧机后补测 |
