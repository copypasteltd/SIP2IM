# 11 许可证合规

> 版本 1.0 · 2026-11-20 · 非法律意见；正式分发前建议专业复核

## 1. 策略

- 本项目自有代码：MIT。
- 允许直接依赖：MIT、BSD-2/3、ISC、Apache-2.0、Zlib；字体 OFL-1.1；素材 CC0。完整依赖与版本以开发约束文档 02 为准。
- 有条件允许：LGPL，仅以动态链接或独立进程方式使用，不修改其源码并入本仓库；在 THIRD_PARTY_NOTICES 中声明。
- 禁止并入：GPL、AGPL、SSPL 及无许可证代码。参考其公开原理须独立实现，不复制代码。
- 专有组件（如 QQ 官方客户端）：不随项目分发，由用户自行安装。

## 3. 流程

每新增依赖：记录名称、版本、许可证、来源链接 → 对照第 1 节 → 写入 THIRD_PARTY_NOTICES.md。CI 中加入许可证扫描（M2）。
