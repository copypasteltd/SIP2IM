# 01 需求规格说明

> 版本 1.2 · 2026-11-20 · 关联：[架构](02-系统架构设计.md)、[验收](08-测试与验收计划.md)、[决策](10-决策与风险登记.md)

## 1. 范围

**包含：** 设备接入与管理、短信收发与转发、浏览器经手机外拨、蜂窝来电转 QQ/TG 原生语音、QQ/TG 发号码触发外呼并回拨、QQ/TG 发消息命令发短信、QQ 与 Telegram 桥接账号登录与用户配对、单管理员多语言 Admin。

**不包含（非目标）：** SIP/PBX；多管理员与角色权限；多租户；MMS/RCS；历史短信导入；录音、转写、AI；群发短信；紧急呼叫；远程 APK 升级与任意远程命令；数据备份；项目内 TLS；来电在浏览器接听；除“接通中”外的任何合成提示音。

## 2. 用户与角色

| 角色 | 说明 |
|---|---|
| 管理员 | 唯一后台用户，拥有全部权限 |
| QQ 配对用户 | 通过 QQ 通道配对的唯一用户 |
| Telegram 配对用户 | 通过 Telegram 通道配对的唯一用户 |

两个配对用户都接收短信转发、来电与未接提醒、告警，都可发号码外呼与消息命令发短信；**语音来电只转给“来电平台”的配对用户**。

## 3. 硬约束（均为已决定）

| 编号 | 约束 |
|---|---|
| C-01 | 不使用 SIP、SIP 协议栈、PBX 或任何 SIP 相关组件 |
| C-02 | 项目代码 MIT 开源；不并入 GPL/AGPL 代码（见 11） |
| C-03 | 手机免 Root；允许 Shizuku；不使用蓝牙、声卡等外接硬件（充电线接服务器 USB 口不算外接硬件） |
| C-04 | 单个业务 APK，向下兼容 Android 4.4（API 19），按系统版本分级启用能力（见 03） |
| C-05 | 架构支持 20 台以上设备；当前只测试 1 台：努比亚 Z20 |
| C-06 | 仅一位管理员；服务器上所有操作以 root 执行，不新增系统用户 |
| C-07 | 原生部署于 Local-server；禁止 Docker、WSL 及其他虚拟化 |
| C-08 | 内网部署；关闭 CORS 校验；项目不配置 TLS，公网与 HTTPS 由用户自理 |
| C-09 | 业务数据永久保存、原样存储、不脱敏；不做备份；不处理磁盘风险 |
| C-10 | 配对成功即生效，无复核，配对用户获得来电与外呼完整授权 |
| C-11 | 号码消息立即拨号，无二次确认，无任何频率或次数限制 |
| C-12 | **QQ 与 Telegram 两个平台通道可同时存在**，各 1 个桥接账号、各 1 个配对用户；短信两边都收；**来电只转给管理员指定的一个“来电平台”**；没有按 SIM 的路由指派 |
| C-13 | 外呼回铃**优先透传运营商音频**；采不到时**循环播放“接通中”提示语音**；除此之外不生成任何提示音 |
| C-14 | 号码区域：中国大陆 +86 与香港 +852 |
| C-15 | 多语言：Admin、APK、机器人回复与提示语音支持简体中文、繁體中文（香港）、English |
| C-16 | 数据库使用 PostgreSQL |

## 5. 号码解析规则

清除空格、短横线、括号后：

| 输入形式 | 解析 |
|---|---|
| `+86…` / `0086…` | 中国大陆 E.164 |
| `+852…` / `00852…` | 香港 E.164 |
| 其他 `+` 或 `00` 国际前缀 | 拒绝 |
| 11 位，以 1 开头 | +86 手机 |
| 以 0 开头、10–12 位 | +86 固话（含区号） |
| 8 位，以 2–9 开头 | +852 |
| 3–6 位短号 | 紧急号码（110、119、120、122、112、999）拒绝；其余原样拨出 |
| 其他 | 拒绝 |

分隔符支持半角 `/` 与全角 `／`。短信命令中号码之后的第一个空格起为短信内容。

## 6. 非功能需求

| 编号 | 需求 |
|---|---|
| NFR-01 | 同时连接 ≥ 20 台设备；20 台心跳与 5 路通话下核心服务 CPU < 1 核 |
| NFR-02 | 局域网单向音频延迟目标 ≤ 400 ms |
| NFR-03 | 状态变化到 Admin 显示 ≤ 3 秒 |
| NFR-04 | 核心服务异常退出由 systemd 重启；进行中通话标记 UNKNOWN 对账，不重拨 |
| NFR-05 | 呼叫与短信动作带唯一请求 ID，幂等 |
| NFR-06 | 凭据不写入日志与仓库 |
| NFR-07 | Admin 支持桌面 Chrome / Edge 最新两个大版本 |
| NFR-08 | 服务端代码兼容 Node.js 20 与 22 |
