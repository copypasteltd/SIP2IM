## 1. 设备控制协议（WebSocket）

- 地址：`ws://<server>:47860/ws/device`；首条 hello 携带设备令牌，5 秒内未认证断开。
- 消息：UTF-8 JSON

```json
{ "v": 1, "type": "sms.received", "id": "evt_01J...", "ts": 1794700000000, "payload": { } }
```

### 1.1 设备 → 核心

| type | payload 主要字段 | 说明 |
|---|---|---|
| hello | token, apkVersion, protocol, model, apiLevel, locale | 认证与版本协商 |
| heartbeat | battery, charging, network, shizuku, paused | 每 30 秒 |
| status.snapshot | sims[{slot, subId, carrier, state, reportedNumber}], capabilityLevel(L1–L5), probes{smsSend, smsReceive, dial, answer, downlink, uplink} | 连接后及变化时 |
| sms.received | eventId, subId, from, body, receivedAt, parts | 至少一次 |
| sms.result | taskId, state(sent/failed/delivered/unknown), errorCode | |
| call.incoming | callId, subId, from | |
| call.state | callId, state(ringing/dialing/alerting/active/disconnected), cause | |
| ack | refId, ok, error | |

### 1.2 核心 → 设备

| type | payload | 说明 |
|---|---|---|
| hello.ok | deviceId, serverTime, config | |
| sms.send | taskId, subId, to, body | 先 ack 后执行 |
| call.dial | callId, subId, to, earlyMedia(true) | 拨号即开始下行采集 |
| call.answer | callId | 仅在平台腿已接通后发送 |
| call.reject | callId | 不应答结束 |
| call.hangup | callId | |
| call.dtmf | callId, digits | P1 |
| ack | refId | |

## 2. 音频通道（WebSocket 二进制）

地址 `/ws/media?session=<id>&leg=<id>`。帧结构（小端）：

| 偏移 | 长度 | 字段 |
|---|---|---|
| 0 | 1 | 版本 = 1 |
| 1 | 1 | 格式：1 = 8 kHz，2 = 16 kHz，3 = 48 kHz（PCM16 单声道） |
| 2 | 1 | 标志：bit0 = 早期媒体（接听前的下行音频）；bit1 = 服务器播放的“接通中”提示语音 |
| 3 | 1 | 保留 |
| 4 | 4 | 序号 uint32 |
| 8 | 4 | 采集时间戳 ms uint32 |
| 12 | n | 20 ms PCM |

抖动缓冲目标为 60～120 ms，最多保留 15 个序号槽；Core 不播放自接收到播放已超过 300 ms 的帧。已认证且仍获授权的通话腿连续 2 秒无新帧入队时记录 `media_stalled`，不以断流推断通话结束。帧中的采集时间戳不用于计算该年龄。

## 3. Admin API（REST，JSON，`Authorization: Bearer`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/login · /api/auth/logout | 登录/注销 |
| GET | /api/dashboard | 统计、通道状态、告警 |
| POST | /api/devices/binding-codes | 生成绑定码 |
| GET / PATCH / DELETE | /api/devices · /api/devices/:id | 列表、修改、解绑 |
| PUT | /api/sims/:id/number | 登记号码（旧接口，无条件写入） |
| PUT | /api/sims/:id/number/conditional | 仅当号码与读取时一致时更新 |
| GET / POST | /api/sms | 查询 / 发送（Idempotency-Key） |
| GET | /api/sms/idempotency | 用 Idempotency-Key 请求头只读查询已有出站短信和任务 |
| GET / POST | /api/calls | 记录 / 浏览器外拨 |
| POST | /api/calls/:id/hangup · /api/calls/:id/dtmf | 挂断 / 按键 |
| GET | /api/channels | QQ 与 Telegram 两个通道的状态 |
| PUT | /api/channels/inbound | 指定来电平台（qq / telegram） |
| POST | `/api/channels/:platform/login` · `/login/submit` · `/logout` | 平台账号控制；提交步骤需要当前 `challengeId` |
| GET | `/api/channels/:platform/login/step` | 只读当前挑战或空值，不重发登录 |
| POST | /api/channels/:platform/pairing-code | 为该通道生成配对码 |
| GET / DELETE | /api/channels/:platform/paired-user | 查看 / 解除该通道配对 |
| GET | /api/outbound-requests | 消息外呼与短信命令记录 |
| GET | /api/alerts · /api/audit-logs | 告警与操作日志；告警页支持 `state` / `limit` / `cursor` |
| POST | /api/alerts/:id/ack | 仅确认开放告警，与操作日志同事务 |
| GET / PUT | /api/settings | 默认设备、语言、超时、短信速率 |
| WS | /ws/admin · /ws/media | 实时事件 / 浏览器音频 |

## 4. 适配器 IPC（Unix socket）

路径 `/run/voip-gateway/adapter-qq.sock`、`/run/voip-gateway/adapter-telegram.sock`（两个适配器同时运行），权限 0600。控制为换行分隔 JSON，音频为同一 socket 上的二进制帧（格式 3）。

| 方向 | type | 说明 |
|---|---|---|
| 核心→适配器 | account.login / account.logout / account.status | 登录 |
| 核心→适配器 | message.send | 向用户发文本 |
| 核心→适配器 | call.dial / call.hangup | 平台一对一语音 |
| 适配器→核心 | account.state | logged_out / login_pending / logged_in / offline / banned / error |
| 适配器→核心 | message.received | senderId, chatType, forwarded, text, messageId |
| 适配器→核心 | call.state | ringing / connected / ended / failed + cause |
| 适配器→核心 | capabilities | dial, receiveAudio, sendAudio, maxConcurrentCalls |

## 5. 数据库（PostgreSQL 14，库 voip）

时间字段 timestamptz；业务数据不删除、不脱敏（C-09）；令牌与配对码只存哈希。

| 表 | 主要字段 |
|---|---|
| admin | id, username, password_hash, failed_count, locked_until |
| admin_session | token_hash, expires_at |
| device | id, name, enabled, paused, call_enabled, default_sim_id, model, api_level, capability_level, apk_version, created_at, revoked_at |
| device_credential | device_id, token_hash, created_at, revoked_at |
| binding_code | code_hash, expires_at, used_at |
| sim | id, device_id, slot, sub_id, carrier, state, first_seen, last_seen |
| sim_number | sim_id, number_e164, source(reported/manual), updated_at |
| device_status | device_id, field, value jsonb, observed_at, received_at |
| sms_message | id, device_id, sim_id, direction, peer, body, event_id unique, ts, received_at |
| sms_task | id, sms_message_id, state, error, idempotency_key unique, updated_at |
| call_session | id, kind(web_out/platform_in/platform_out), state, created_at, ended_at, end_cause |
| call_leg | id, session_id, type(cellular/platform/browser), ref_id, state, timeline jsonb |
| call_event | id, session_id, leg_id, event, payload jsonb, ts |
| channel | platform(qq/telegram) 主键（最多两行）, enabled, account_alias, platform_user_id, state, updated_at |
| paired_user | id, channel_platform, platform_user_id, display_name, paired_at, revoked_at（每个平台同一时间仅一条未撤销） |
| pairing_code | id, code_hash, expires_at, used_at, used_by |
| pairing_attempt | sender_id, ts, ok |
| outbound_request | id, kind(call/sms), platform, paired_user_id, message_id unique, raw_text, from_sim_id, to_number, body, state, session_id, replies jsonb |
| alert | id, type, subject_id, severity, state, first_at, last_at, pushed_at |
| audit_log | id, action, target, detail jsonb, ts |
| setting | key, value jsonb（含 inbound_platform、sms_forward、bot_language、sms_rate_limit 等） |

迁移脚本只增不删。
