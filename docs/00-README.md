# VOIP 多设备安卓短信与电话网关 · 文档体系

> 版本 1.3（基线草案）· 2026-11-20 · 状态：需求已冻结、方案待门槛验证 · 项目许可证：MIT

## 1. 项目一句话

用多台常开的旧安卓专机（免 Root、无外接硬件）作为 SIM 网关，由一台内网服务器统一管理短信收发、浏览器通话，以及 QQ / Telegram 原生语音的来电转接和消息触发外呼。**全系统不使用任何 SIP 相关技术。**

## 5. 术语

| 术语 | 含义 |
|---|---|
| 网关设备 / Device | 安装业务 APK、插有 SIM 的安卓专机 |
| SIM 槽 | 设备内一张 SIM；一台设备可有 1–2 个 |
| 核心服务 Core | 服务器上的主进程：API、设备连接、呼叫协调、数据库 |
| 平台适配器 Adapter | 独立进程，封装 QQ 或 Telegram 的登录、消息与原生语音 |
| 桥接账号 | 适配器登录的 QQ/Telegram 普通账号，代表系统收消息、打语音 |
| 配对用户 | 通过配对码绑定的 QQ/TG 用户，接收来电转接、可发号码外呼 |
| 腿 Leg | 一通桥接中的一侧通话：蜂窝腿、平台腿、浏览器腿 |
| Shizuku | 以 shell 身份运行特权代码的独立安卓应用，免 Root |
| 延迟接听 | 蜂窝来电保持振铃，平台侧真实接听后才接听蜂窝 |
