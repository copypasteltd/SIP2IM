# 13 前端设计规范与原型

> 版本 1.0 · 2026-11-20 · 状态：10 套方向原型已完成，**待用户选型** · 关联：[Admin 设计](06-Admin后台设计.md)、[Android 设计](03-Android网关设计.md)

## 1. 范围

- **Admin**：浏览器管理后台（桌面 Chrome / Edge）。
- **APK**：安卓网关应用，原生界面，最低 Android 4.4。
- 原型位置：`VOIP/prototypes/`，入口 `index.html`。

## 2. 原型说明

| 项目 | 说明 |
|---|---|
| 打开方式 | 直接双击 `prototypes/index.html`，或用任意静态服务器打开；无外部依赖、无网络请求 |
| 页面 | Admin：仪表盘、设备列表（含绑定码）、设备详情、短信、通话（进行中通话 + 浏览器拨号 + 通话记录）、平台通道（QQ 与 Telegram 双通道 + 来电平台 + 配对码 + 登录方式）、外呼与命令、告警、设置、登录；APK：绑定、运行状态、能力探测 |
| 对比方式 | 每套右上角可切换方案与语言（简体 / 繁體 / English），当前页面保持不变 |
| 数据 | 10 套共用同一份示例数据与页面结构，差异只在视觉与布局；示例中的 GW-02（Android 14）、GW-03（Android 4.4）为演示设备，实际只测试努比亚 Z20 |
| 性质 | 静态 HTML / CSS / JS，只用于方向选型，不是实现代码 |

## 3. 所有方案共同遵守的约束

### 3.1 状态语义

| 状态 | 含义 | 表现 |
|---|---|---|
| ok | 正常、在线、已验证、已发送 | 实心圆点 + 文字 |
| warn | 需关注、需实测、未接 | 实心圆点 + 文字 |
| err | 离线、失败、拒绝 | 实心圆点 + 文字 |
| unk | 未知、不适用、待验证 | **空心圆点 + 虚线边框** + 文字 |
| live | 通话中 | 圆点脉动；全站唯一的持续动效 |

规则：不只靠颜色区分（形状 + 文字）；每个状态附更新时间或心跳；过期显示“未知”；“在线”与“可通话”分开显示（06 第 2 节）。

### 3.2 数据显示

- 号码完整显示（C-09 不脱敏），等宽字体，按 `+86 138 0013 8000` / `+852 6123 4567` 分组。
- 时间 24 小时制；表格内时间等宽右对齐倾向。
- 能力等级 L1–L5 以等宽小徽标显示。

### 3.3 多语言

三种语言；英文文案长度预留 +40%；图片中不放文字；号码、编号不翻译；繁体使用香港用语。

### 3.4 无障碍与交互

- 正文对比度 ≥ 4.5:1，大字与图标 ≥ 3:1。
- 焦点可见；表格行可用回车进入详情；开关使用 switch 语义。
- 触控目标：Admin ≥ 32 px，APK ≥ 48 dp。
- 尊重“减少动态效果”设置。
- 危险操作（解绑、挂断、登出）使用危险色，并与普通操作分开摆放。

### 3.5 布局与适配

Admin 以 1440 宽设计，1280 完整可用；≤ 1180 双栏改单栏；≤ 860 导航改为顶部横向滚动；表格横向滚动不截断。

### 3.6 APK 实现约束（Android 4.4 起）

| 约束 | 原因 |
|---|---|
| 原生 View + AppCompat，不用 WebView 渲染界面 | 4.4 WebView 老旧、性能差 |
| 不依赖实时模糊、动态取色 | 需 Android 12（API 31） |
| 阴影在 4.4 用 layer-list / 9-patch | elevation 需 API 21 |
| 图标用 VectorDrawable（支持库兼容） | API 19 需 useSupportLibrary |
| 使用系统字体，不打包中文字体 | 控制 APK 体积 |
| 动效只用于状态变化与通话中 | 旧机性能 |

### 3.7 设计令牌

| 令牌 | 含义 | APK 对应 |
|---|---|---|
| --bg / --surface / --surface-2 | 页面底色 / 卡片 / 次级容器 | colors.xml |
| --text / --muted / --line | 正文 / 次要文字 / 分割线 | colors.xml |
| --primary / --primary-ink | 主操作色及其上的文字 | colorPrimary |
| --ok / --warn / --err / --unk / --live | 状态色（第 3.1 节） | colors.xml |
| --radius / --radius-sm | 圆角 | dimens.xml |
| --font-display / --font-body / --font-mono | 标题 / 正文 / 等宽 | 系统字体映射 |
| --shadow | 阴影 | elevation / layer-list |

## 5. 选型方式

- 选 1 套；或混搭（例如 Admin 用 02、APK 用 05）；也可以指出要调整的点（颜色、密度、布局）。
- 选定后产出：完整设计令牌、组件规范（按钮、表格、状态、表单、对话框、通话面板）、全部页面高保真、APK 原生资源映射，并据此进入 M2 前端开发。
