# 2026-11-21 工作日志 / Maintenance log

## 入站短信通知与数据库连接隔离 / Incoming SMS notification and pool isolation

- Core 读取已提交的通知标记和短信后，先归还读取连接，再认证订阅者并广播。短信入库与通知标记仍原子提交，设备 ACK 不等待广播。
- 广播返回后，另开短事务按原事件 ID 和微秒时间清理对应标记。替换标记不会被误删；清理结果未知时先读回，可能重复更新提示，不代表浏览器签收或短信重发。
- 停止或启动失败冻结新通知；正常停机等待已开始的工作。观察到所有权丢失时拦截尚未发出的通知与清理。已发出的操作无法撤销。
- Core returns the read checkout before authorizing subscribers and broadcasting. A later short transaction deletes only the original event and exact timestamp. An uncertain cleanup can repeat a hint, not resend an SMS. Device ACK and history semantics are unchanged.
- Stop or failed startup freezes new attempts. Graceful shutdown drains admitted work, and observed ownership loss fences work not yet issued.
