## 本轮变更 / Changes

- 短信发送回执按原绑定、连接、任务和分段核对。Core 持久保留矛盾证据、阻止普通回执覆盖冲突状态，并可对精确重复事件重新计算投影。硬件发送仍只允许原任务的一次申领。
- Core 接通 `C-ALR-01` 的四项设备健康规则，再次超时会形成新告警。Android SIM 观测失败时仍可上报独立的短信权限。Web 告警页每 30 秒读回。
- QQ/TG 的 IPC 接收路径校验共享 ACK、时间戳和 UTF-8。软件设备模拟器加入内存通话夹具，覆盖替换连接、通话代次和合成媒体故障。
- 使用独立的原生 Chrome 实录仪表盘、设备告警、绑定取消和模拟短信。复现方法见[发布检查清单](../../RELEASE-CHECKLIST.md#demo-capture--演示录制)。

- Android and Core bind send results to the original claim and preserve contradictory evidence. Core rebuilds an older projection when it receives an exact duplicate event.
- The health reconciler handles four device alert types. The Web alert page refetches every 30 seconds.
- QQ/TG IPC tests cover shared ACK, timestamp and UTF-8 validation. A test-only simulator covers call generations and media failures. The synthetic walkthrough includes the updated alert page.
