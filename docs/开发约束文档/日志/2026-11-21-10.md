# 2026-11-21 工作日志 / Maintenance log

## 平台登录挑战与只读恢复 / Login challenges and read-only recovery

- 错过登录步骤时，Web 只发鉴权、不缓存的 GET。返回挑战前 Core 核对原管理员会话、挑战与操作状态。连接、会话或挑战变化使旧结果不可用；不会自动重新发起登录。
- Core 为每个新提示生成挑战 ID。提交绑定原平台、连接和挑战，即使只是产生同名新步骤，旧资料也不能下发。适配器 IPC 仍只接收步骤和值，不传挑战 ID；未知操作不重发。Core 和 Web 须协调升级。
- A missed prompt can be read back with one authenticated, no-store GET. Core rechecks administrator authority, the exact challenge, and idle operation status before returning a step. Late results cannot reopen a retired challenge or restart sign-in.
- Submissions bind the original challenge, attachment, and platform. A replacement with the same step name retires the old challenge. Adapter IPC still receives only the step and value. Upgrade Core and Web together.
