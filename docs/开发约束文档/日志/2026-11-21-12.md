# 2026-11-21 工作日志 / Maintenance log

## Android 握手超时恢复 / Android handshake timeout recovery

- WebSocket 打开后，Android 在当前连接上用单调时钟判断 10 秒接纳窗口。即使定时回调尚未执行，过期的 `hello.ok` 也不能应用配置或开启心跳、队列。计时器不唤醒休眠设备。
- 超时主动结束本次连接，不等旧连接回调。旧回调不能影响新连接。确认原持久代次释放后才按现有退避重连；终止性关闭和释放不明仍须核对。保留待发事件，不改变协议或设备 ACK。
- Each open WebSocket gets a ten-second monotonic hello window. An expired reply cannot apply configuration or start heartbeats and queue dispatch, even if the timer callback is delayed. The timer does not wake a sleeping device.
- Expiry retires only the original connection without waiting for a transport callback. Normal retry requires confirmed release of its durable generation. Terminal observations and uncertain release remain fenced. Pending events and the wire contract are unchanged.
