## Core 设备命令回执截止 / Core device command ACK deadline

- Core 开始本地发送才计 10 秒；按单调时钟及原设备、当前连接、命令 ID 接纳匹配 ACK。处理到期的正负 ACK 都不作结果证据。计时器、连接替换和发送错误只结算同一在途记录；过期不关闭健康连接。
- 生产短信由传输层统一裁定 ACK，保留已申领原尝试的未知结果，不用新命令重发。独立设备结果仍可核对。幂等配置和旧夹具的处理边界不变。
- Core applies one monotonic ten-second window starting at the local send. An ACK must match the device, current attachment, and command ID and be processed before expiry. A late positive or negative ACK does not settle the command as accepted or refused. Retired callbacks cannot settle another attempt.
- The production SMS path uses the bounded transport result and keeps an unresolved original claim unknown without replay. Separate device results still provide reconciliation evidence. An ACK is not proof of an external outcome.
