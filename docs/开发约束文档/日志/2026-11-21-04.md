# 2026-11-21 工作日志 / Maintenance log

## 告警分页与确认审计 / Alert history and acknowledgement audit

- Core 按数据库原始微秒时间和 ID 分页，游标绑定状态。旧请求不提供分页参数时保持兼容。Web 告警页每 30 秒读回当前页，仪表盘最多请求 5 条开放告警。不活动页不参与后台刷新。
- 核验原管理员会话后，告警确认与审计在同一事务提交。重复确认不会另写审计；审计失败则回滚。未知响应需读回，不自动重试。
- Alert paging uses the exact timestamp and ID, with a state-bound cursor. The admin console polls the current page only and the dashboard fetches up to five open alerts. Legacy unpaged clients retain their original behavior.
- Acknowledgement and audit commit together after session revalidation. A repeat does not create another audit entry, and the UI reads back rather than automatically retrying an uncertain mutation.
