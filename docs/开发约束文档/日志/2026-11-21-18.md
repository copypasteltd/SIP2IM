# 2026-11-21 工作日志 / Maintenance log

## Core 适配器账号命令回执截止 / Core adapter account command ACK deadlines

- 本地 IPC 写入开始后 10 秒为正常回执截止。迟到存证以同一截止为起点，最晚 30 秒后结束，不受定时回调顺序影响。只有相同有效连接和命令的首个匹配正 ACK 可存证。
- 迟到正 ACK 只为原持久操作写终态证据，不改变 504，也不自动释放。迟到负 ACK 消耗存证机会，过期或换代后不能接纳。已接纳的存证写入仍排空，不重发账号命令。
- Core admits a normal ACK before the ten-second monotonic cutoff. The late-evidence window ends 30 seconds after that fixed cutoff; delayed timers do not extend it. Only a positive first matching ACK for that command on the same live link can record evidence.
- Late positive evidence belongs to the original durable operation. It cannot undo HTTP 504 or release the operation automatically. A late NACK consumes the opportunity without evidence. Admitted evidence writes drain, with no command replay.
