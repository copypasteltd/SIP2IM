# 2026-11-21 工作日志 / Maintenance log

## 运维告警 / Operational alerts

- 在 f5fc23f 基线上接入渠道掉线、通话失败或结果未知、协议不兼容、Shizuku 自启失败告警。复用既有状态和告警表，没有新增迁移、协议字段或通话能力。
- 渠道状态与告警在同一事务保存，正常停机与初始化不作为故障。通话告警扫描独立于通话命令与 ACK。协议告警先核验设备和原凭据，诊断不能改变准入。自启报告没有源时间或观察 ID，5 秒去重只是保守的近似规则。
- Web 以三语显示告警类型和状态。新版合成演示核对确认后的接口读回，区分「已确认」与「已解除」。
- On top of f5fc23f, Core now records channel outages, failed or uncertain calls, incompatible device protocols and repeated Shizuku autostart failures. This update does not change the schema or wire fields, or enable calling.
- The synthetic Web capture shows acknowledgement, not recovery, while the separate device warning remains open. See the [verification record](../../VERIFICATION.md) and [release notes](../../../CHANGELOG.md).
