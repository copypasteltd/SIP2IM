# 2026-11-21 工作日志 / Maintenance log

## Web 管理连接超时恢复 / Web admin connection timeout recovery

- 管理连接分别限制 WebSocket 打开和首个 `pong` 的等待时间，各 10 秒。就绪后以 60 秒单调时钟窗口判断活性；最多一个 `ping` 待应答。超时、错误或发送失败先淘汰本地连接并撤销计时器，再尽力关闭旧 socket，不等关闭回调才重连。
- 重连按 1、2、4、8、16、30 秒退避，并绑定当前会话版本和连接。恢复后只请求一次查询刷新。旧提示被废弃；在途或结果未知的写入保留原操作，不自动重放。
- WebSocket open and first pong each have a ten-second budget. Ready-state freshness uses a 60-second monotonic window with one outstanding ping at most. Timeout, error and send failure retire locally before best-effort close; retry does not wait for a close callback.
- Retries are fenced by socket and session generation and capped at 30 seconds. Recovery asks for one cache invalidation. Retired hints cannot revive old prompts. Pending or uncertain writes are not replayed.
