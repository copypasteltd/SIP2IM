## Core 设备握手与接管截止 / Core device handshake and takeover deadline

- Core 从接管 `/ws/device` 连接起计固定五秒。令牌核验通过不停止计时；配置读取、设备串行队列和开始提交 `hello.ok` 仍在同一个单调时钟窗口内。接管前已经超时的候选不替换现有连接。命令目标在本地提交应答后才登记。
- 较新候选及时通过鉴权后，即使后续超时，也不回退让更早的候选接管。观察到的关闭、可归属的撤权和代次冲突仍优先。关停禁止新工作，并等待已接纳的查询和队列；五秒不是排空时限。
- Core uses one monotonic five-second window for first device `hello`, auth, configuration, and the start of local reply submission. A candidate expired before takeover leaves the incumbent alone. Command readiness follows local reply submission, not remote receipt.
- A newer timely authentication still fences older candidates. Observed closure and applicable revocation or generation fences retain precedence. Shutdown freezes new work and still joins admitted work without suspending the deadline.
