# 2026-11-21 工作日志 / Maintenance log

## 适配器握手与管理通知 / Adapter handshake and admin notifications

- Core 按 IPC 代次处理握手。初始能力先暂存；首条账号状态、有效登录能力和适用告警同事务提交。提交命令发出前复核连接与独占所有权；提交未知不假定回滚，也不重发账号操作。
- 管理通知退出 ACK 路径。每平台一个在途任务与每类一个最新槽，读回或推送失败不会拒收已提交的报告；过时代次或失效提示不再发送。关停拒绝新增任务并排空在途工作。
- The initial capability ACK confirms staging only. The first state ACK follows confirmed account, login capability, and alert persistence. The runtime rechecks current attachment and ownership; uncertain commits are not treated as rollbacks or replayed.
- Admin notices are bounded and independent of IPC ACKs. Replacement and retired prompts are fenced at delivery. The UI does not automatically recover missed prompts, and this does not enable platform messages, pairing, or calls.
