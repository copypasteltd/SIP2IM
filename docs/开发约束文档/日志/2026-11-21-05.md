# 2026-11-21 工作日志 / Maintenance log

## 短信跨设备调度与快照唤醒 / Cross-device SMS scheduling and snapshot wakeups

- 持久队列每次最多发现 32 台设备，按设备 ID 继续扫描。派发最多同时处理 4 台设备，最多保留 256 个普通待处理唤醒，重复提示合并。超出上限只丢弃提示，短信任务仍可通过后续扫描发现。
- 有设备等待且本轮达到 2 秒时，完成在途步骤后让位，下一轮继续轮转 SIM。保持每 SIM 的 FIFO，超时或未知结果不重发。暂停和关停不接纳普通新工作，已开始的发送与结果写入仍排空。
- 新快照提交后仅在原连接仍是当前连接、且 Core 未关停时请求重新检查；快照本身不授予发送资格。保留心跳与周期恢复。
- Recovery discovers up to 32 devices per page. Four device turns and 256 ordinary waiting hints limit dispatch admission. Discarded hints leave durable tasks intact. When another device is waiting, long turns yield between tasks and resume SIM rotation.
- A committed snapshot on the current attachment can wake an eligibility recheck. Heartbeats and periodic scans remain fallbacks. Uncertain sends are never repeated.
