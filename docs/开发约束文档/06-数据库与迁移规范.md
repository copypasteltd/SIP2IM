# 06 数据库与迁移规范

> 版本 1.1 · 2026-11-20 · PostgreSQL 14，集群 voip，库 voip，角色 voip · 本文**取代**需求文档 04 第 5 节的列名

## 1. 约定

- 迁移文件：`core/migrations/NNNN_<描述>.sql`，四位序号递增；**只增不改**。
- 迁移表：`schema_migration(version int primary key, applied_at timestamptz not null default now())`。
- 启动时 core 自动执行未应用的迁移，每个迁移在单独事务内。
- 主键：`text`，存带前缀的 ULID。时间：`timestamptz`。JSON：`jsonb`。
- 所有表含 `created_at timestamptz not null default now()`；可变表含 `updated_at`。
- 不建立级联删除；业务数据不删除（C-09）。外键 `on delete restrict`。
- 令牌、配对码、绑定码只存 SHA-256 哈希（`bytea`）；管理员密码存 Argon2id 编码字符串。

## 5. 数据访问规则

- 只有各模块 `repo.ts` 写 SQL；全部使用参数化查询。
- 设备锁与通道锁不存数据库，存 core 内存（单进程）；重启后以 call_session 中未结束会话对账。
- 列表查询必须走索引；新增查询如无索引须在迁移中补建。
- 连接池上限 10。
