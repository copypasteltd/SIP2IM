## 2. 路由

| 路径 | 页面 | 需登录 |
|---|---|---|
| /login | 登录 | 否 |
| / | 重定向 /dashboard | 是 |
| /dashboard | 仪表盘 | 是 |
| /devices、/devices/:deviceId | 设备列表、设备详情 | 是 |
| /sms、/sms/:threadKey | 短信 | 是 |
| /calls、/calls/:sessionId | 通话 | 是 |
| /channels | 平台通道 | 是 |
| /commands | 指令记录 | 是 |
| /alerts | 告警 | 是 |
| /settings | 设置 | 是 |
| /audit | 操作日志 | 是 |

core 对所有非 `/api`、`/ws`、静态资源的 GET 返回 index.html（前端路由回退）。

## 3. 数据层

- **服务端状态只放 TanStack Query**；zustand 只放会话、语言、主题、当前浏览器通话。
- 查询键工厂（keys.ts）：`['devices']`、`['devices', id]`、`['sms','threads',filters]`、`['sms','thread',key]`、`['calls',filters]`、`['calls',id]`、`['channels']`、`['alerts',state]`、`['settings']`、`['dashboard']`、`['commands',filters]`、`['audit']`。
- 默认 `staleTime` 30 秒；实时推送负责更新。
- 列表分页用 `useInfiniteQuery` + 游标。
- 写操作用 `useMutation`；成功后按 cache-sync 规则更新相关键；发短信、外拨自动生成 Idempotency-Key（ULID）。

## 4. 实时同步规则（admin-socket.ts）

| 推送事件 | 缓存动作 |
|---|---|
| device.updated / online / offline | setQueryData(['devices',id])；更新 ['devices'] 列表中对应项；失效 ['dashboard'] |
| sms.new | 使 `sms` 前缀查询失效，从 REST 读回，不把广播载荷追加到会话。 |
| sms.task.updated | 使 `sms` 前缀查询失效，以 REST 记录为准。 |
| call.updated | setQueryData(['calls',id])；更新进行中通话列表 |
| channel.updated / channel.login.step / pairing.updated | setQueryData(['channels']) 或推入登录步骤状态 |
| alert.raised / resolved | 失效 ['alerts',*] 与 ['dashboard']；导航徽标 +1 |
| settings.updated | setQueryData(['settings']) |

断线恢复收到首个有效 `pong` 后，请求失效全部查询一次，由各查询按需读回；不是全部请求已成功的证明。WebSocket 打开与首个应答各限时 10 秒，后续 60 秒无有效应答即淘汰当前连接；不等待旧关闭回调。会话版本、当前连接与时限共同限制消息处理；重连不重放命令。

## 5. 鉴权

- 登录成功的 token 存 `localStorage`（会话 7 天，单管理员内网；CORS 已关闭校验，故不使用 Cookie，见 ADR-007）。
- api/client.ts 统一加 `Authorization: Bearer`；收到 401 清除 token 跳转 /login 并保留原路径。
- /ws/admin 与 /ws/media（浏览器腿）连接后**首条消息**发送 `{"type":"auth","token":"…"}` 认证（05 §4.1、§6.4）；**不得把令牌放进 URL**（会进入请求日志）。

## 6. API 基址

默认同源（core 托管前端）。开发时 Vite dev server 通过 `VITE_API_BASE=http://192.0.2.10:47860` 直连服务器（服务端 CORS 全开，无需代理）。

## 7. 浏览器通话音频

1. 进入拨号前调用 secure-context.ts：`window.isSecureContext && navigator.mediaDevices?.getUserMedia`。不满足时拨号按钮禁用，并显示说明（Chrome 内网例外设置方法，或 HTTPS 代理）。
2. `getUserMedia({ audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true, channelCount: 1 } })`。
3. 创建 `new AudioContext({ sampleRate: 48000 })`；若浏览器不接受该参数，读取实际 `sampleRate`，capture worklet 使用通用重采样（线性插值 + 低通）转为 16 kHz，**不得假设固定 3:1**；累计 320 样本（20 ms）后发给主线程，主线程按 05 §4.2 封帧（format = 2）发送。
4. 接收帧 → playback worklet：抖动缓冲目标 80 ms，16 kHz → 上下文实际采样率重采样；缺帧补静音；带 bit1（提示语音）与 bit0（早期媒体）的帧照常播放，并把标记通知 UI（跳线图显示“接通中提示”/“回铃透传”）。
5. 通话结束：停止轨道、关闭 AudioContext、关闭 WebSocket。
6. 帧编解码复用 `packages/protocol/src/media.ts`，不重复实现。

## 8. 多语言实现

- i18next，命名空间按 feature：common、lines、sms、calls、channels、commands、alerts、settings、audit、auth、errors。
- 语言：zh-CN（默认）、zh-HK、en；切换即时生效并保存到 session store 与服务端 admin.locale。
- 字体由主题令牌 `--font-*` 决定；如主题为中文区分简繁字体，用 `html[lang]` 选择器在 theme.css 中覆盖。
- 键缺失时开发模式控制台报错，CI 中用脚本校验三份语言文件键集合一致。
- 日期与数字用 `Intl` 按当前语言格式化。

## 9. 主题

- theme.css 定义 `:root` 变量（令牌名见 10 §2）；若主题提供深色版本则以 `[data-theme=dark]` 覆盖。Tailwind `@theme` 把令牌映射为工具类（如 `bg-surface`、`text-muted`、`text-ok`）。
- **V01 选定后**：用选定原型的 `prototypes/themes/sXX-*.css` 替换 theme.css 与 theme-decor.css，组件代码不改。
- 首次按 `prefers-color-scheme`，用户选择后保存到 localStorage。

## 10. 质量约束

- TypeScript strict；ESLint（react-hooks、jsx-a11y）；Prettier。
- 每个 feature 至少：页面渲染测试、关键交互测试（Testing Library）。
- Playwright 端到端（对接 core + 设备模拟器）：登录、线路列表、发短信、生成配对码、设置保存。
- 性能预算：首屏 JS（gzip）≤ 300 KB；自托管字体（若有）每种 ≤ 400 KB；设备列表 25 台渲染 < 100 ms。
- 不引入 CDN 资源；所有资源随构建产物分发。
