## 3. 必测清单（每类代码的最低要求）

| 代码 | 必须覆盖 |
|---|---|
| 号码解析 | 需求文档 01 第 5 节每一行，含全角分隔符、紧急号码、超区域号码 |
| 命令解析 | 配对码两种格式、短信命令、单号码、拨出号码/目标号码、群聊/转发/非配对用户忽略、未知文本 |
| 状态机 | 每个状态的每个出口事件；超时；重复事件；乱序事件（如 connected 先于 ack） |
| 来电转接 | **平台未接听时绝不向设备发送 call.answer**（属性测试：随机事件序列下该不变式成立） |
| 外呼 | 被叫先接 / 用户先接两种顺序；早期媒体有/无两种情况下的提示语音切换 |
| 锁 | 设备锁、通道锁并发获取；会话结束一定释放；重启对账释放 |
| 短信 | event_id 去重；未知状态不重发；速率限制排队 |
| 配对 | 过期、重复使用、错误锁定、替换旧配对、并发两次提交同一码只成功一次 |
| 媒体 | 三种格式帧编解码；重采样频响（1 kHz 正弦往返误差）；抖动缓冲积压丢帧 |
| 鉴权 | 登录锁定；令牌过期；解绑时现有连接以 4010 关闭，之后用旧令牌连接返回 4003；禁用设备连接返回 4011；/ws/admin 与 /ws/media 首条消息认证，失败 4403 |
| 绑定 | POST /api/device/bind：成功、过期 410、已用 400、并发同码只成功一次、IP 限流 429 |
| ack 语义 | 05 §3.4 表中每条命令的 ok 与 ok:false 分支；10 秒无 ack 记 unknown 且不重发 sms.send / call.dial / call.answer |
| 配对与号码 | 未配对者发 8 位数字 → 配对；已配对者发 8 位数字 → +852 外呼；已配对者发“绑定 NNNNNNNN” → 配对 |
| 日志 | 请求日志中不出现 Authorization 与 token |
| CORS | 任意 Origin 预检返回 204 且带允许头 |
| i18n | 三语键集合一致；机器人模板变量齐全 |

## 4. 测试环境

- **PostgreSQL 测试库**：集成测试只读取环境变量 `VOIPGW_TEST_DATABASE_URL`，每次测试前重建 schema。两种提供方式（ENV-11）：
  - 方案 A（默认）：Local-server voip 集群中的独立库 `voip_test`，经 SSH 端口转发到本机 127.0.0.1:47432。依赖 D-02 与服务器访问权限（13 §0）。
  - 方案 B（需用户同意）：本机 `.toolchain/pgsql` 中的 PostgreSQL 14 Windows 免安装版（原生进程，不是虚拟化），仅监听 127.0.0.1。
  - 无法访问服务器且未获方案 B 同意的 agent：只运行单元测试，集成测试任务标 BLOCKED。
  - 禁止连接 voip 以外的任何集群。
- **假设备**：core/test/fakes/fake-device.ts，实现设备协议，可脚本化事件。
- **假适配器**：core/test/fakes/fake-adapter.ts，实现 IPC，可脚本化 connected/ended 时序。
- **禁止**：测试中访问真实 QQ/Telegram、真实拨号、真实短信。

## 5. 质量门禁（合并到 main 前）

1. `npm run check` 与对应 Android / Python 检查全部通过。
2. 新增代码行覆盖率：core 业务模块 ≥ 80%，状态机与解析器 100% 分支覆盖。
3. 三语键一致；许可证检查通过。
4. 无 `console.log` 残留（使用 logger）；无 TODO 注释未登记到 14。

## 6. 真机与门槛证据

- 证据目录：`VOIP/evidence/<门槛>/<日期>/`（已在 .gitignore 中，不入库；路径写入日志）。
- 内容：audio-probe 报告、录音文件、设备日志（logcat 过滤本应用）、core 日志片段、通话 ID、测试员听测结论。
- 用 16 号文档“门槛证据”模板汇总。

## 7. 平台门槛用例定义（G2 / G3）

| 编号 | 步骤 | 期望 |
|---|---|---|
| TC-TG-01 / TC-QQ-01 | 在 Admin 完成桥接账号登录 | account.state = logged_in，Admin 显示已登录；重启适配器后无需重新登录 |
| TC-TG-02 / TC-QQ-02 | 测试用户（已互加好友）私聊发送文本；系统回复文本 | message.received 字段完整（senderId、private、forwarded=false）；回复送达 |
| TC-TG-03 / TC-QQ-03 | core 发起 call.dial；测试用户手机响铃后接听 | 适配器先报 ringing，**测试用户真实点击接听后**才报 connected；拒接时报 ended 且原因为拒接 |
| TC-TG-04 / TC-QQ-04 | 接通后 audio-probe 播放测试音并录制平台下行；双方挂断各一次 | 测试用户听到测试音；录音中可辨认测试用户朗读的数字；任一侧挂断另一侧 3 秒内结束 |

四项全部通过后，管理员才可在 Admin 将该通道 voice_verified 置为 true。
