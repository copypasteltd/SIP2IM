| 环境 | 版本 | 说明 |

| 服务器系统 | Ubuntu 22.04.5 LTS x86_64 | Local-server 192.0.2.10 |

## 4. Android APK

|---|---|---|
| 语言 | Kotlin（AGP 配套稳定版） | |
