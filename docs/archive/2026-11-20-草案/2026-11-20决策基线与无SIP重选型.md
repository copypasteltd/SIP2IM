# 2026-11-20 决策基线与无 SIP 重选型

> 本文件优先于此前与之冲突的草案；未开始实现、部署或真实电话测试。用户确认的目标不代表技术已验证。

## 已确认

- 至少 3 台设备，后续 20 台以上；设备常开专用；不接外部蓝牙、声卡或其他新增硬件组件。
- 单个管理员，不建设复杂多用户角色权限系统；管理员登录、设备凭据、配对身份和基本授权仍需实现。
- 项目以 MIT 开源；完全不使用 SIP、SIP 协议栈或 PBX。
- 用户要求发送配对码完成绑定即生效，不作管理员二次确认；配对后同时具备来电接听及消息拨号完整授权。必须保留一次性高熵码、过期、限流、真实 sender ID、撤销及配对成功提示；码泄漏即可能被抢占，风险明确。
- QQ/TG 消息格式为 {拨出号码}/{目标号码} 或 {目标号码}；前者选对应 SIM，后者使用默认设备/SIM；消息立即拨号，先拨蜂窝后回拨平台用户。号码不存在/未知/重复匹配时拒绝，不擅自选择；号码无法可靠读取可管理员登记，不能当身份凭据。
- 来电目标未接则蜂窝侧不应答；运营商计费、语音信箱不保证。
- 业务数据永久保存、不做脱敏；保留账号和凭据保护，不在代码或日志写密码/验证码/session 密钥；不要求备份。
- 首先内网、关闭 CORS 校验，用户自行公网转发及 TLS；不将开放 CORS 视为认证机制，保留单管理员身份验证与设备认证。
- 本地不使用 Docker/WSL 或其他虚拟化环境，云端按原生进程方案；操作目标服务器只能按授权执行，生产部署需明确授权。

## 技术选型：无 SIP 新架构候选，不是已验证结论

Android：Kotlin 原生 + Android SMS/Telecom + 经许可独立实现的 Shizuku 通话音频适配；信令：TypeScript + NestJS + WebSocket，数据库 PostgreSQL，前端 React + TypeScript；媒体优先评估 WebRTC 或音频流网络桥（直接设备/服务器媒体，不使用 SIP）。具体媒体库、QQ/TG 适配均须验证许可证、构建与运行时兼容；浏览器麦克风和 WebRTC 在普通非本地主机 HTTP 内网可能受安全上下文限制，后续由用户提供的 HTTPS 代理或其他经验证安全上下文解决。WebRTC 本身常要求 DTLS/SRTP 等协议内建加密，与用户不配置 TLS 证书是不同层次，不承诺关闭协议强制加密；部署前确认。

原 android-voice-sip-agent 为 GPL 并使用 SIP，不能直接将其代码或其 SIP 模块并入并改标 MIT；KoishiRTC 为 GPL-3.0-only，亦不可直接改标 MIT；进程隔离也不能自动断言不存在 GPL 义务。可以参考公开知识、Android 文档和协议行为，由独立实现、依赖许可证审查和必要法律评估论证；具体无 SIP、MIT、QQ/TG 原生双向语音和免 Root 手机音频是否能够同时达成目前未验证，不得承诺可行。要么找到许可兼容并实际可用的实现，要么按用户目标做独立实现或另行协商许可证，不能擅自改变目标。

## 核心验收与现实约束

1. 至少三台真实设备绑定及 SMS/状态管理；设计及容量测试覆盖 20 台以上，实际并发用户未给定，不将设备数等同通话并发。
2. 手机蜂窝来电在平台用户接听之前保持未应答，QQ/TG 未接或拒绝不应答；无 SIP 架构必须证明端到端状态时序与运营商现场行为。
3. 发送单号码用默认设备，发送拨出号码/目标号码按已登记 SIM 号码唯一匹配，合法授权后立即启动蜂窝外呼再向发送者回拨；先被叫接听可能收费；失败按原呼叫 ID 清理不盲重拨。
4. 平台用户配对成功即授权；绑定范围按已批准规则及撤销机制实现，来电与去电均生效。
5. 业务记录永久原样保存、不做业务数据脱敏；不等于采集密码、session 等秘密。保护与存储容量/法律限制仍需在实际部署前评估。
6. 无备份需求，不实施计划性备份；不可承诺故障后数据可恢复。
7. 所有已接受原推荐且涉及具体事实的项目（手机型号、服务器信息、平台顺序等）不能凭空推定。

## 风险与实施门槛

| 风险 | 当前状态/处理 |
|---|---|
| MIT 与 GPL 上游 | 冲突：禁止直接拿现有 GPL 代码重新授权 MIT；审查可替代的 MIT 兼容依赖和专有 QQ 组件 |
| 无 SIP | 现有电话网关和 SIP-PBX 桥方案作废，必须重新实现/验证电话状态和媒体链路 |
| 通话音频 | 免 Root + Shizuku 可行是上游项目声明；独立 MIT 实现尚未证明，设备 ROM、硬件和系统差异重大 |
| 开放 CORS + 本地 HTTP | 增加跨站请求及内网访问风险；身份鉴权、设备绑定、抗 CSRF/Origin 风险另行设计；安全上下文限制不可绕过 |
| 永久明文展示 | 数据长期聚集可能暴露隐私；保留权限与凭据保护，不额外改变用户的保存和展示需求 |
| QQ/TG | 独立原生通话及目标服务器架构、许可证与账号条款尚未证明 |
