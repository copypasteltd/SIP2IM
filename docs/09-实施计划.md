# 09 实施计划

> 版本 1.2 · 2026-11-20 · 门槛驱动

## 1. 里程碑

| 里程碑 | 内容 | 退出条件 | 并行关系 |
|---|---|---|---|
| M0 准备 | 本机工具链（JDK 17、Android SDK、Gradle）、本地 git 仓库 voip-gateway、许可证白名单、服务器复核 | 能构建空 APK | — |
| M1 G0 | 最小 APK（minSdk 19，能力探测、Shizuku、呼叫控制、L4/L5 音频）、最小 core（设备 WS、音频录放） | G0 结论 | 与 M2、M4a、M4b 并行 |
| M2 核心 + 短信 + Admin | PostgreSQL 集群与迁移、绑定、状态、短信、多语言 Admin | TC-DEV/SMS/ADM | 与 M1 并行 |
| M3 浏览器外拨 | 媒体路由、浏览器音频腿 | G1 | 依赖 M1、M2 |
| M4a QQ（优先） | Q-A 路线：客户端、协议端、注入宿主、配对、来电、外呼 | G3 | 与 M1 并行起步 |
| M4b Telegram | T-A 路线：Telethon + 通话库、配对、来电、外呼 | G2 | 与 M4a 并行 |
| M5 规模与上线 | 设备模拟器（纯软件）20 台以上、告警推送、部署 | G4 + 部署授权 | — |

M1 失败时：M2 照常交付；M3/M4 的平台登录、配对、消息部分仍可完成，语音部分暂停等待用户决定。
